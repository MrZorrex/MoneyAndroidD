# PaySplit

**PaySplit** — офлайн-приложение для Android, которое распределяет каждую зарплату
по вашим счетам и помогает контролировать расходы.

Приложение работает **полностью без интернета**: нет серверов, рекламы, аналитики
и каких-либо сетевых запросов. Все данные хранятся только на телефоне
(база Room, шифрование стандартное для системы).

---

## Что умеет приложение

| Раздел | Возможности |
| --- | --- |
| **Онбординг** | 4 шага: приветствие, примерный доход, количество выплат в месяц, выбор шаблона категорий |
| **Главная** | Прогресс получения зарплаты, доходы/расходы/остаток за месяц, круговая диаграмма расходов, список счетов с балансами, последние операции, быстрый перевод между счетами |
| **Поступление** | Автоматический расчёт распределения суммы по счетам пропорционально остаткам плана, ручная корректировка с пересчётом остальных, свободные средства после закрытия всех планов |
| **Расход** | Список счетов с текущим балансом, подсказки по названиям трат, быстрые шаблоны, предупреждение о перерасходе, «сохранить и добавить ещё» |
| **Счёт** | Баланс, прогресс по плану, график баланса за 6 месяцев, операции по месяцам, быстрая трата, пополнение с другого счёта, удаление операций и счёта |
| **Категории** | Добавление и редактирование счетов, выбор иконки, тип «оплата сразу» или «накопительный», целевая сумма и дата, включение/отключение, изменение порядка перетаскиванием, сброс по шаблону |
| **История** | Фильтры по периоду (месяц, прошлый месяц, 3 месяца, полгода, год, всё, свой), типу операций и категории, группировка по дням, итоги, удаление операции с подтверждением |
| **Аналитика** | Обзор, расходы по категориям, накопительные счета с прогнозом до цели, самые большие и частые траты, тренды доходов и расходов |
| **Настройки** | Доход и количество выплат, PIN-код, вход по отпечатку пальца, тема (система/светлая/тёмная), Material You, уведомления, экспорт CSV и PDF, резервная копия и восстановление, удаление всех данных |
| **Блокировка** | Ввод PIN-кода на цифровой клавиатуре или отпечатком пальца, автоматическая блокировка при уходе в фон |

## Технологии

- **Kotlin**, **Jetpack Compose**, **Material 3** (Material You, тёмная/светлая тема по системе)
- **Room** — локальная база данных
- **Vico 2.4.3** — столбчатые и линейные графики (круговая диаграмма рисуется на Canvas)
- **WorkManager** — вечерние напоминания
- **Navigation Compose** — навигация между экранами
- **BiometricPrompt** — вход по отпечатку пальца
- `minSdk = 35` (Android 15/16), `targetSdk = 36`, `compileSdk = 36`

## Сборка и запуск в Android Studio

### 1. Что нужно установить

1. **Android Studio** (версия Narwhal 3 / 2025.x или новее) — скачать с
   [developer.android.com/studio](https://developer.android.com/studio).
2. **Android SDK Platform 36** (Android 16). Устанавливается через
   *Tools → SDK Manager → SDK Platforms*.
3. **JDK 17** — входит в состав Android Studio (используется встроенный JBR,
   дополнительно ничего устанавливать не нужно).

### 2. Открыть проект

1. Распакуйте архив с проектом (если он пришёл архивом).
2. В Android Studio выберите **File → Open…** и укажите папку проекта —
   ту, в которой лежат файлы `settings.gradle.kts` и `gradlew`.
3. Дождитесь окончания **Gradle Sync** (первый синк может занять несколько минут:
   Gradle скачает зависимости из Maven Central и Google).

### 3. Запустить на телефоне или эмуляторе

1. Включите на телефоне режим разработчика и отладку по USB
   (или создайте эмулятор в *Device Manager*).
2. Нажмите зелёную кнопку **Run ▶** (или `Shift + F10`).
3. Выберите устройство и дождитесь сборки.

> Приложение установится как `com.paysplit.app` (для отладочной сборки —
> `com.paysplit.app.debug`).

### 4. Собрать APK без Android Studio

```bash
# Отладочный APK
./gradlew assembleDebug
# Готовый файл: app/build/outputs/apk/debug/app-debug.apk

# Релизный APK (подписан отладочным ключом — удобно для установки)
./gradlew assembleRelease
# Готовый файл: app/build/outputs/apk/release/app-release.apk
```

Отладочный APK ставится на телефон командой:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 5. Тесты и проверка

```bash
./gradlew test          # модульные тесты (JVM)
./gradlew lint          # проверка ресурсов и манифеста
./gradlew assembleDebug # полная сборка
```

## Как пользоваться

1. **Первый запуск** — пройдите онбординг: укажите примерный доход в месяц,
   сколько раз приходит зарплата и загрузите шаблон категорий (12 готовых счетов).
2. **Пришла зарплата** — нажмите кнопку «Пришла зарплата!» на главном экране,
   введите сумму. Приложение само посчитает, сколько нужно распределить
   на каждый счёт, чтобы закрыть планы месяца. При необходимости нажмите
   «Скорректировать» и введите суммы вручную.
3. **Трата** — кнопка «Расход»: выберите счёт, введите сумму и название.
   Рядом с каждым счётом виден его текущий баланс.
4. **Счета** — в разделе «Категории» можно менять планы, добавлять свои счета,
   отключать ненужные и менять порядок перетаскиванием за значок «≡».
5. **Защита данных** — в настройках установите PIN-код и/или включите вход
   по отпечатку пальца. Приложение будет блокироваться при уходе в фон.
6. **Резервная копия** — настройки → «Создать резервную копию» (файл `.db`),
   восстановление — «Восстановить из копии» (приложение перезапустится).
7. **Экспорт** — CSV (все операции) или PDF-отчёт за выбранный месяц;
   файл можно отправить в любое другое приложение через системный диалог «Поделиться».

## Важные детали реализации

- **Баланс счёта** = сумма всех распределений + переводы на счёт − расходы − переводы со счёта.
- **Распределение зарплаты** пропорционально остаткам `план − уже распределено`
  по всем активным счетам; если поступление закрыло все планы, остаток
  показывается как «свободные средства».
- **Накопительные счета** копят остаток, у расходных счетов остаток переносится
  на следующий месяц.
- **Удаление** любой операции или счёта требует подтверждения, а удаление всех
  данных — ввода слова `УДАЛИТЬ`.
- **После восстановления** резервной копии процесс приложения перезапускается,
  чтобы Room открыл новый файл базы.

## Частые вопросы

**Не синхронизируется Gradle.** Проверьте подключение к интернету (первый синк
качает зависимости) и что в *Settings → Build Tools → Gradle* выбран
Gradle JDK 17.

**Ошибка «SDK location not found».** Создайте файл `local.properties`
в корне проекта со строкой `sdk.dir=/путь/к/Android/sdk`
(Android Studio обычно создаёт его сам).

**Нет эмулятора.** Достаточно запустить на реальном телефоне с Android 15+.

**Релизная подпись.** Сборка `assembleRelease` использует отладочный ключ.
Чтобы публиковать приложение, создайте свой keystore и подключите его
в `app/build.gradle.kts` в блоке `signingConfigs`.
